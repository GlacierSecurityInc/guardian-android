# Encrypted WebRTC Calls

Media in Peer-to-Peer Rooms is end-to-end encrypted; Glacier never decrypts media. Each participant negotiates a separate DTLS/SRTP connection with every other participant; SRTP is encrypted at the sender and decrypted at the receiver only. Glacier does not mediate media; TURN relays only encrypted SRTP if needed (no decryption or manipulation). OMEMO fingerprints: DTLS fingerprints are encrypted using OMEMO and carried in the `urn:xmpp:jingle:jet-omemo:0` / `http://gultsch.de/xmpp/drafts/omemo/dtls-srtp-verification` namespace, created in `AxolotlService.encrypt(...)` and decrypted in `AxolotlService.decrypt(...)` into standard `urn:xmpp:jingle:apps:dtls:0` fingerprints. Verification behavior: `JingleRtpConnection.receiveRtpContentMap(...)` expects OMEMO-verified fingerprints when available; `Config.REQUIRE_RTP_VERIFICATION` controls whether verified fingerprints are mandatory.
